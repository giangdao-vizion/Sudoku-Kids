# Sudoku Kids

Game Sudoku dành cho trẻ em 3–7 tuổi — thuần HTML, CSS và JavaScript (không framework).

## Chơi ngay

Mở `index.html` trong trình duyệt, hoặc chạy server tĩnh:

```bash
python3 -m http.server 8080
```

Rồi vào `http://localhost:8080`.

## Tính năng

- Chọn bảng: **1×4**, **1×9**, **4×4**, **9×9**
- **4×4** và **9×9** có chế độ Easy / Medium / Hard
- Nút **Gợi ý** khi đang chơi
- Chạm ô trống → hiện bảng chọn số (không cần nhập bàn phím)
- Giao diện mobile-first, nút to, màu sắc vui nhộn
